## Identification hints
- It is all about to gather a set of data that can then help you identify an entity
- A folder, a file, a code snippet, etc
- It can be anything, the more better

## external git repos
- lets say i want to identify an external git repo
- the obvious hint is just the path, but it can change
- what else can/should i do?
- I can store a set metadata for a number of commits
    - eg: commit hashes, timetag, authors, etc
- I can store the remotes
- I can store the branch names

## A file
- I can get the file path
- I can get the file size
- I can get the file hash
- I can get the file creation date
- I can get the file modification date
- I can get the file type
- I can get the file content snippet (first 100 bytes?)
- I can get a random sample of bytes/words from the file
- I can get the surrounding files in the folder

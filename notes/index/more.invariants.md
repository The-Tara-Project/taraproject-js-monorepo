
## Tapes/Records
- Immutability: Once data is written to tapes, it is immutable
- Unified Format: All data flows through tape/record format for consistency
- Append-Only Tapes: Tapes can only be appended to, never modified in-place

## Apps
- No Enforced Workflow: Minimal intervention policy - flexibility over prescription

## Stack
- Centralized Storage: home folder (~/.taraproject) as default source of truth
- Data Ownership: Full user control of data, all local and open

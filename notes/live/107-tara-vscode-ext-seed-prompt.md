## Tara-vscode-extension

I want you to create a VSCode extension called "Tara-vscode-extension" that integrates with the Tara system. 

At the moment I want you to only add read capabilities for Tara.
Similar to the tara-cli.

### Capabilities
- a panel with a list of all tapes in Tara
    - Include some statistics about each tape (size, number of files, date created, date modified)
    - If selected, open the tape file in vscode as read-only
- A search bar to filter tapes by name or metadata

I mean, be creative with the UI/UX design, but keep it simple and intuitive.
    - and read only
